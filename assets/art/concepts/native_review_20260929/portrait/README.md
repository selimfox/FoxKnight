# 狐狸 E 菜单头像：原生像素静态设计样张

状态：**待审的 48×48 头像草案**，不是正式 UI 图标、游戏角色图集或用户审美签收。此处只研究 R3 菜单的狐狸头肩像能否在小画布上保留 E 的身份。

## 文件

- `draw_portrait.py`：可复现的逐格色块绘制源。所有轮廓、明暗、眼、颊毛、短吻与围巾都用原生整数坐标手工编排；不读取、采样、缩小或滤镜处理 E 概念图。
- `fox_E_portrait_native_48.png`：48×48 RGBA 原生可逐像素编辑稿，透明度仅 0/255。
- `fox_E_portrait_review_2x.png`：严格最近邻 2×，96×96；用于和拟定菜单尺寸比较。
- `fox_E_portrait_review_4x.png`：严格最近邻 4×，192×192；用于看色块、孤立点与轮廓。

运行：`python draw_portrait.py`。脚本会重建上述三个 PNG；若在 PNG 中直接手修，请先同步改动到脚本或另存新版本，避免下次重建覆盖。

## 造型与来源

依据本项目 `docs/art/ArtIteration_Revision_R2_2026-09-28.md` 的 E 方向和 `docs/art/UI_Revision_R3_2026-09-28.md` 的头像要求，参考本项目原创概念图 `assets/art/concepts/review_20260928_r2/fox_E_identity_concept.png` 的高耳、橙额、向短吻卷入的奶油颊毛、机敏睁眼与酒红围巾。查阅日期 2026-09-29。没有使用外部贴图或该概念图的任何像素作为源数据。

本稿在有限面积内保留两侧高度略不同的耳、两团有尖端的白颊、小鼻、眼睑与少量棕色虹膜、偏左的围巾折面及低亮钢肩。脸部大色团优先于毛发噪点，围巾与肩甲不盖住眼鼻。它有意比高分辨率 E 概念简化。

## 本次检查与限制

源图在 1× 下绘制，2×/4×仅复制像素；脚本检查所有 alpha 只为 0 或 255。目视检查了 4× 放大图，耳、脸、围巾与肩部可分开识别。**这只是一张静态头肩像。** 下半脸在 2× 尺寸仍呈较大奶油色连片，微笑与颊毛的细腻程度明显弱于 E 概念，需要创作者判断它是合适的像素化概括还是继续修订。尚未把它放进真实 960×540 菜单与标题同框，也没有检查各屏幕比例、四方向角色、动作或表情一致性。

菜单头像的最终尺寸、锚点与引用入口必须在同框审定后由 Coding 核对；本目录没有修改场景、脚本、正式资源或任何旧文件。
