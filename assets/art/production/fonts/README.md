# 中文 UI 字体来源

本目录于 2026-09-26 从 Noto 官方仓库取得 `NotoSansCJKsc-Regular.otf` 和随附的 `OFL-LICENSE.txt`，用于狐狸骑士的可编辑中文界面文字。字体是独立第三方资产，不是本项目原创像素字稿；禁止把其来源误写为自制。文字仍由 Godot Label/Button 实时排版，不烘焙进背景图。

- 字体原文件：https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf
- 对应许可证：https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE
- 本地字体 SHA-256：`2C76254F6FC379FDDFCE0A7E84FB5385BB135D3E399294F6EEB6680D0365B74B`
- 许可证：SIL Open Font License 1.1；`OFL-LICENSE.txt` 必须随可分发字体保留。

它解决正式中文字符覆盖与授权来源，不自动解决“艺术字”的造型问题。标题字形、字重、像素边缘和小字号显示仍要在 960×540 游戏内审美复核，必要时另做原创可编辑标题字，而不能把普通字体叫艺术字。
