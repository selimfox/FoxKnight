## 来源与界限

- 设计基线：`docs/GDD.md` v0.1 的俯视角、暗黑幻想、直接控制狐狸与唯一一刀；`docs/art/VisualPackagingAudit.md` 的角色可读性需求。三关及追踪士兵属于当前构建事实，尚非 GDD 正式版本范围。
- 参考：用户于 2026-09-26 提供《赛菲利亚》截图（只比较一致像素密度、大色块和动作清晰度；没有复制角色、道具、UI 或贴图）；同日用户认可新概念图中圆脸、短吻、饱满白颊和蓬松白尾的方向。`fox_silhouette_study.js` 的 C 方案虽在原生网格绘制，却未成功承接该审美方向；`build_round_characters.js` 动作稿仅保留为被否定稿的技术记录，不应继续扩展。
- 狐狸维持橙毛、浅口鼻、轻灰甲、酒红围巾和短银剑；士兵为暗紫护甲、浅青面罩。**用户认可的是圆脸轮廓方向，不是当前整套动作和实机场景的最终审美签收。**

### 动画建议（须与真实事件重新对时）

图集按 `front → side → back → left`，每方向按下表状态排列；实际 rect 以 `frames.json` 为准，图集 8 列，每帧 32×36 原生像素。`duration_ms` 只是首轮观感建议，**不得用它替代判定/提交时点**。

| 角色 | 状态 | 帧 | 建议循环 | 关键信息 |
| --- | --- | ---: | --- | --- |
| 狐狸 | idle | 2 | 是 | 轻微呼吸，脚底不动 |
| 狐狸 | walk | 4 | 是 | 双脚交替，身体轻弹 |
| 狐狸 | ready | 2 | 是 | 剑举起，仍可取消瞄准 |
| 狐狸 | straight | 4 | 否 | 预备→刺出→抵达→收势；起手/判定由程序重定时 |
| 狐狸 | arc | 6 | 否 | 手腕与刀尖绕身体改变位置，躯干有独立转重心；**不旋转整张贴图** |
| 士兵 | idle | 2 | 是 | 不举刀、不伪装攻击预告 |
| 士兵 | chase | 4 | 是 | 前进步态；接近停下后回 idle |
| 士兵 | hit | 2 | 否 | 短亮边为受击；不是生命值反馈 |
| 士兵 | death | 4 | 否 | 倒下收束；尾帧投影应减弱/撤去 |

## 制作与检查

在本目录运行 `node build_round_characters.js` 可重建 PNG、`frames.json` 和检查图。原生 PNG 可在 Aseprite/LibreSprite/GIMP 等以 1×倍率编辑；如手工在 PNG 上修改，之后运行脚本会覆盖这些修改，应同步到源稿或另起版本，不直接覆盖。运行 `node verify_sprites.js` 检查帧数、rect、透明硬边、2×最近邻逐像素对应与非空动作帧。

2026-09-27 的技术检查：`node verify_sprites.js` 对当前文件通过 72 帧狐狸、48 帧士兵的硬 alpha、图集范围、非空帧、动作差异与 nearest 2× 逐像素一致性检查；这只证明像素图集结构有效。狐狸的视觉方向未通过用户审美验收，不能因技术检查通过而继续接入或交付。
