# 狐狸骑士 UI 第一批正式组件（资源包 v1）

> 2026-09-26。此包是可逐像素修改的第一批共用 UI 组件，已接入当前 Godot 菜单、三关 HUD 与结算；功能与截图检查通过，但尚未获得创作者审美定稿。基于目前 `campaign.tscn` 的四入口，以及三关共用的 `prototype_hud.tscn/gd`。只表达当前已有状态、输入、胜败分支；不添加地图、生命值、商店或剧情入口。

## 视觉目标与参考边界

- 使用暗黑幻想、俯视像素战场的冷灰蓝石质语言；按钮和通用焦点用低饱和古金色，不挪用弧斩暖橙或直斩冷青作为无关操作状态。环境试用轮廓色 `#171D2B`、墙色 `#252D40`、石色 `#30394F`、亮面 `#47546A`、冷高光 `#65748B`；本批 UI 色值尚非全项目锁定色板。
- 创作者提供的《赛菲利亚》两张截图仅用于分析统一像素尺度、界面信息层级、紧凑边框和字形可读性；没有复制画面布局、图标、角色或受保护像素。截图来源：本轮用户附件，访问日 2026-09-26。
- 中文已接入 `assets/art/production/fonts/NotoSansCJKsc-Regular.otf`，Godot Label/FontFile 继续持有真实可编辑文本；授权文件与源地址见字体目录 README。菜单和胜败专用字标已另做原创像素资源，见 `assets/art/production/title/`；Regular 继续服务正文与可编辑回退。

## 源与导出

`generate_ui.py` 是确定性的可编辑绘制源；`native/*.png` 是 1:1 原生 RGBA 像素画，可在像素工具中逐点编辑；`export/*.png` 是最近邻 2 倍的游戏贴图。修改脚本后重跑会覆盖这两个派生目录，所以若直接修 `native`，先将修改同步回绘制源或另存新版本。所有图只用直线、矩形、固定色块，无 AI 缩图、半透明毛边或现成游戏素材。

## 像素、九宫格与锚点

- 原生逻辑像素 `1` = 当前 960×540 视口的 `2` 物理像素；原生场景画布 480×270。所有核心边线宽 1 原生像素，导出后 2 游戏像素；Godot 导入应使用 nearest/filter off，整像素位置，不能将 32 像素图标拉到当前 38×38 非整数比例。
- 按钮每帧取 `Rect2(0, 54*i, 240, 54)`，`i=0..4`。四边九宫格边距 6 游戏像素。normal/hover/pressed/focus/disabled 五个 StyleBoxTexture 复用同一图集；按下仅视觉内缩，不让 Godot 再给文本作额外非整数缩放。文本垂直中线为按钮高度中心。
- HUD 与结算九宫格各使用 16 游戏像素四边边距；中心可拉伸，边框/角块不拉伸。结算已改为下沿 660×146 浅条，避免旧 420×250 中央面板遮住默认编排下的幸存敌人；极端新编排仍须实机检查遮挡。
- 菜单图层固定中心锚 `Vector2(0.5, 0.5)`，960×540 保持 1:1；不同宽高比只扩展 `#101520` 底色及边缘暗石，不把整张图线性拉伸。按钮与可读文字保持视口中心安全区：横向 156–804、纵向 66–456 游戏像素。HUD 左上保持现有 `(24,18)`，观察／瞄准提示靠下沿；结算出现时提示带隐藏，下沿浅条接管信息。
- 层级：菜单底石 < 菜单饰边 < 标题/说明 < Buttons/焦点；战斗场景 < HUD 面板/提示带 < 图标/数字/Label < 结算面板 < 结算按钮/焦点。菜单和结算装饰不可遮住可点击区域或鼠标焦点。

## 文本与交互方案（不改规则）

- 菜单标题 `狐狸骑士` 建议 42–46 游戏像素的中文标题字，正文 16–18，按钮 18–22；保持既有四按钮和输入说明原文，若三关正式命名未定，继续显示“关卡 1/2/3”，不添章节地图或锁图标。
- HUD 常驻部分已收为刀图标＋余刀数字、追兵图标＋存活数字，去掉 `一刀 1/1`、`目标 N` 的调试式词条。观察期操作提示只短暂显示一次，进入瞄准时短显“松开出刀／右键取消”，提交后隐藏；菜单原型副标题和永久键位行已隐藏。图标和颜色不能替代首次玩家对“一次攻击、全灭过关”的理解，仍需单独试玩验证，不凭精简界面宣称教学问题解决。
- 按钮的悬停是石面提亮加古金边；键盘焦点另有亮色内描边；按下明度回落；disabled 保持灰色且不表现可点击。两种状态不能只凭颜色区别，边线厚度/内描边有形状差。
- 结算成功/失败由实际结果选择像素字标，原 Label 保留回退；中性边框本身不讲战斗结果。失败后默认编排的幸存目标在下沿浅条上方仍可见，已用三关实机截图检查；未来重新布置敌人时仍须复核。

## 完成度与接力

第一批组件和第二批字标已接入当前菜单、三关共用 HUD 与胜败结算，短开场 glint 与真实焦点帧已接入，Godot 运行截图和功能检查见 `output/ui_production_*.png`。创作者明确否定旧常驻文案的廉价感；紧凑图标/逐像素数字只是修正后的第一版，仍须实际试玩确认语义、标题与菜单密度、动效节奏及新编排下的结果遮挡。成功运行与具备贴图不能替代正式审美验收。
