## 原创性与参考

项目早前提供的《赛菲利亚》截图只作为像素比例、墙体体积和色块组织的分析参考；原有来源记录为 TEAM HORAY 的 [Steam 官方页面](https://store.steampowered.com/app/2436940/Sephiria/)，于 2026-09-26 记录在相邻 `environment/README.md`。本包没有采样、描摹、缩小截图或概念图。庭院气氛另参考项目自身 `assets/art/concepts/level01_mood_A_courtyard_study_v2.png`，只取冷月与边缘暖火关系。代码源 `build_environment.py` 调用项目未接入的 `environment/pixel_stone_forms.py` 与 `pixel_water_edge_forms.py` 原生像素绘制函数，再在 16 像素格手工调整色板和局部像素；独立水岸和六帧火焰同样直接绘于原生格。若以后清理旧运行贴图，应保留这两个绘制依赖或将其迁入本包。

浅水本身可通行。水图集的可见水像素为二值 alpha，倒影 mask 与同格水面逐点同位，边缘最外一像素不出倒影；湿石过渡格无倒影。水下石块用大色面与短石缝表现，不画成封闭双椭圆。Coding 接入时应从实际水 TileMap 格位生成当前帧倒影，并在脚底离开 mask 时关闭；反射强度、步伐水纹和光向仍按已批准范围动态复核。水 atlas 可继续使用当前 `WaterSurface` source ID 1，但 `water_surface.gd` 的 mask 路径与 atlas 尺寸需同步。选择水边格要根据邻格朝向，不能随机摆放孤立外岸格。

三关地编建议：01 的左上湿区连接已有水域，北/西少量苔；02 让中部错缝更直、更干，边缘少量布条但不画成路标；03 中央优先安静 A/B，破损集中外围四侧且避开敌人轮廓。新增水、墙、地编都不能遮挡脚底或瞄准几何。实际三关的角色站位、池位置、火盆与墙碰撞沿用当前场景。

## 生成与检查

命令：`python assets/art/production/environment_20260930/build_environment.py`。默认若任一目标存在即拒绝覆盖；只有明确要放弃源稿手工修改时才传 `--force`。脚本产物检查：每张源稿都是 RGBA 16 像素格可编辑，alpha 仅 0/255，导出与源稿最近邻精确 2×；源图不是高分辨率图缩小或像素化滤镜。游戏内观看、动态反射和审美通过仍须另验，静态脚本检查不替代人工验收。

`python assets/art/production/environment_20260930/validate_assets.py` 已检查全部八组成对源/导出、水 mask 严格在可见水内、湿石四格无反射、九格水池连续，以及六帧火焰互不相同且盆口像素完全固定。`render_full_room_study.py` 生成三张 960×540 整房材质试铺，复核后将 Floor 从六宏扩到十二宏、压低中心色差，并移除中央重复苔点。该试铺是资源重复节奏 QA，**不是**三关实际 TileMap 或运行截图。Coding 接入后仍需逐关实机检查演员同框、池岸没有双圈误读、光向、进出水倒影、火焰连续、碰撞及斩击；发现偏差继续修本包。
