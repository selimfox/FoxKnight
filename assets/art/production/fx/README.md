# 战斗像素 FX 首批图集（已接入；主体刀光仍待审美迭代）

日期：2026-09-26。`build_fx.js` 是原生 16×16 整数网格逐像素源稿；运行 `node assets/art/production/fx/build_fx.js` 生成 `fx_native.png`、最近邻 2× 的 `fx_world2x.png` 和 `frames.json`。两张 PNG 可在像素编辑器逐点编辑；若手改导出图，须同步修改源稿或另起版本，避免重建覆盖。图集 RGBA 只用硬边 0/255 alpha，无 AI 缩图，也不含背景。

视觉职责：直斩必须从狐狸到真实终点形成连续冷青刀身，替换 `scenes/combat/prototype_slash.tscn` 对旧 `slash_trail.png` 的依赖，不再把整张旧图任意拉伸；弧斩需用随执行进度转动的单段暖橙像素刀光替换 `prototype_slash.gd` 中的平滑 `draw_arc` 主体，不能退化成完整常亮攻击圈。现有 16×16 点缀图集可保留用于短促火花或刀型切换，但与主体重叠后须检查层级和亮度。命中星芒只在 `hit_enemy` 已成立时播放，绝不触发判定。Coding 负责正式接入、裁剪直斩末段、半径映射、时序测试及替换旧资源引用。

像素约束：所有源稿为独立 RGBA PNG、硬边 0/255 alpha，无滤镜、半透明毛边或高分辨率图缩小。导入设置需用 nearest、关闭 mipmap，默认游戏尺度 2×，不做任意小数缩放。色彩沿用 GDD 第 6.2/6.3 节已确认的冷青直斩／暖橙弧斩，弧光运动对应 GDD P-05/P-09，非新的玩法或范围。美术参考只取项目既有试运行画面 `output/fx_straight_960x540.png`、`output/fx_arc_960x540.png` 的待替换问题，以及创作者于 2026-09-26 提供的《赛菲利亚》截图的**像素颗粒一致性和视觉层级问题**；没有复制其角色、图案或特效。独立逐帧图集已在原生尺寸及 2× 放大下目检，**尚需正式游戏画面复核**：重点看 960×540 下是否与狐狸动作对齐、直斩有无断节、弧斩是否误导范围、闪光是否遮住仍存活敌人。
