# 狐狸骑士手工像素字标与外围交互帧 v1

2026-09-26。此资源包只对应当前运行中的菜单与底部胜败结果带，不新增叙事、按钮或玩法。字标、徽记、焦点和开场帧已接入 Godot 并完成 960×540 与宽屏实机截图、UI/战斗/三关功能测试；**创作者审美验收尚未完成**。

## 规格卡

- 信息：`狐狸骑士` 是游戏身份；`胜利` 与 `失败` 只表现现有结算真值。完整原因、按钮、`R` 提示仍由可编辑 Label/Button 提供；图案不能代替真实 UI 状态。
- 原生逻辑画布按 480×270 设计，游戏视口 960×540。`native/` 为 1:1 RGBA、`export/` 为最近邻 2×；不可再作非整数缩放。笔画、描边与高光以整数像素写在 `build_title.py` 中，亦可逐像素修改原生 PNG；重跑生成器会覆盖派生文件。
- 透明边缘严格 0/255 alpha，字体无抗锯齿；Godot 贴图过滤须 nearest/off。装饰色采用暗石墨、旧金与狐狸围巾的暗红；失败字使用失血红，但不铺红屏；按钮焦点仍是中性金，避免混淆弧斩橙与直斩青。
- 源文本准确为四字「狐狸骑士」、两字「胜利」与「失败」。所有 8 个汉字的骨架均由源代码中独立线段在 32×32 原生格上绘制，未使用 Noto 字形、AI 缩图或其他游戏的字标。拐角采用台阶像素与上下分明的金属亮边；狐狸耳、短剑、围巾小痕是本作身份记号。

## 自检与交接

运行 `build_title.py` 后执行 `verify_title.py`，检查尺寸、最近邻输出、硬 alpha 与预览尺寸。四字在 960×540 菜单中央可辨；胜败两个字在底部结果带左栏可辨，没有盖住按钮或幸存目标。狐狸徽记、真实焦点帧和短开场 glint 已由 `scripts/ui/title_motion.gd` 接入并通过 `tests/acceptance/ui_visual_runner.gd`；静态截图中的横向金色 glint 是短过渡的一帧，不是进度条。**资产工程与功能检查通过，整体美术正式定稿仍待创作者审美验收。**
