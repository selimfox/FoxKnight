# 狐狸骑士 Word 副本同步

## 确认来源与范围

1. 读取仓库根目录 `AGENTS.md` 和定稿的 `docs/GDD.md`。
2. 将 Markdown 视为唯一正式来源；禁止用 Word 内容反向覆盖 Markdown。
3. 只调整 Word 的展示格式，不改变、补充或删减 GDD 设计内容。

## 备份现有副本

- 更新前检查 `docs/GDD.docx` 是否存在。
- 若存在，在统一备份目录中创建带日期时间的备份，例如 `backups/docs/GDD_backup_YYYYMMDD_HHMMSS.docx`。
- 备份目录按根目录 `AGENTS.md` 的规则镜像原文件所在目录，不得把备份散落在 `docs/` 或项目根目录。
- 先确认目标不存在；不得覆盖任何历史备份。
- 若无法安全备份，停止同步并报告原因。

## 生成 Word 副本

1. 根据最新 `docs/GDD.md` 重建或更新 `docs/GDD.docx`。
2. 保持标题层级、列表、表格及中文字体和段落排版清楚稳定。
3. 忠实保留 Markdown 内容与状态标记，不借排版调整改变含义。

## 验证版面

1. 将生成的 DOCX 渲染为页面图像或使用可靠的等效检查方式。
2. 检查文本截断、表格溢出、乱码、意外空白页、孤立标题和标题层级错误。
3. 修复发现的展示问题后重新检查，直到输出稳定。
4. 若当前环境无法安全生成或验证 DOCX，停止同步并说明原因；不得声称已经完成。

## 完成报告

报告：

- 备份路径（若原文件存在）；
- 输出路径；
- 使用的生成与检查方式；
- 发现并修复的排版问题；
- 无法完成的检查或剩余风险。

除非用户明确要求，否则不得进行任何 Git 操作。
