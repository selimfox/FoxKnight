## 1. 核心体验与假设

### 1.1 当前概念 [已确认]

狐狸每次尝试只能挥出一刀。玩家利用左右移动、跳跃和二段跳寻找切入位置，以方向冲击斩命中一个敌人；首次命中进入公开显示的 0.02 倍慢速，鼠标改变这次打击的作用方向，使受击敌人的尸体成为能连续击杀其他目标的弹体。

只有首次命中的 A 可改向、可作为伤害弹体。A 之后命中的 B 普通死亡，不继承冲量、弹体属性或改向能力，不建立尸体间的分叉传播。

### 1.2 体验假设 [待验证]

| ID | 假设 | 观察依据 |
| --- | --- | --- |
| H2-01 | 首击门槛与高低差使出刀前的位置和方向预判有意义 | 玩家能解释切入点，并主动比较其他合法切入方式 |
| H2-02 | 首击后一次改向产生值得尝试的结果差异 | 玩家改变首击位置、目标或方向，而不只等待固定窗口 |
| H2-03 | 尸体运动与碰撞清楚，失败能指导重试 | 玩家指出漏击、碰墙或落地点，并说明下次想改什么 |
| H2-04 | 命中聚焦、强震与慢速改向形成清楚的动作节奏 | 命中有回报，选方向时能读图，确认后能看清结果 |

功能通过、全灭有解、特效强烈不能单独证明这些假设。当前没有 v0.2 运行或试玩证据。

### 1.3 叙事边界

先验证动作与空间体验，不据此确定反 ARPG 的最终哲学立场、玩家身份或世界观。历史叙事设想不自动成为本版需求。

## 2. 玩家流程 [已确认；分支边界见第 8 节]

| 阶段 | 玩家权限 | 世界与系统行为 |
| --- | --- | --- |
| 初始化 | 等待初始化 | 清理上次状态，恢复一次攻击与正常时间 |
| 移动与预判 | 左右移动、跳跃、二段跳、方向输入 | 不同高度提供命中机会；首版敌人静止且不攻击狐狸 |
| 冲击斩 | 提交一次方向冲击斩，之后关闭新的角色战斗输入 | 狐狸沿提交方向冲击；未实际命中不进入慢速 |
| 首次命中与改向 | 鼠标旋转箭头，左键确认 | 唯一首击对象记为 A；世界以 0.02 倍速运动，狐狸继续原冲击 |
| 自动演算 | 无战斗输入 | 应用确认的打击方向，恢复正常时间；A 可连续伤敌 |
| 结算 | 重试或离开 | 全灭为胜；否则等有效伤害过程结束再判失败 |

未命中、调整中 A 提前失效等分支必须在制作前补齐，不由实现默认补全。

## 3. 已确认规则

### 3.1 横版运动与输入

- 侧视 2D 横版，左右移动、跳跃和二段跳。
- WASD 为方向，Space 跳跃，X 攻击；冲击斩支持水平、竖直及组合方向。
- 键盘映射先在 Godot 工程配置中公开可改，不制作游戏内改键页面。
- 高低差服务于接近、瞄准和方向预判，不先制作长篇平台关卡。
- 首版敌人静止，不加入巡逻或攻击狐狸，先集中验证首击与尸体弹体。
- 无方向输入朝向、二段跳恢复等边界见第 8 节。

### 3.2 唯一一刀与冲击

- 每次尝试只提交一次斩击；空挥不返还攻击机会。
- 狐狸沿提交方向位移；实际命中才触发慢速。
- 第一次斩击有效命中的敌人记为 A；A 死亡后成为唯一伤害尸体弹体。
- 出刀关闭新的移动、跳跃及攻击输入，但不能因此停止狐狸既有冲击与物理运动。
- 命中 A 后狐狸继续冲击；是否还能直接斩伤其他敌人是未决项。

### 3.3 慢速与方向箭头

- 首次命中后战斗世界以正常速度 0.02 倍运行，并显示慢速状态。
- 狐狸与 A 都继续运动；不是完全暂停，也不是等待确认后才发射 A。
- 只有 A 开放一次改向，后续尸体伤敌不再触发该状态。
- 箭尾固定在 A 初始受力方向侧的边缘并跟随 A；以箭尾为圆心，鼠标旋转，左键提交。
- 例如狐狸在左向右冲击 A，箭尾在 A 右侧。它是可视标记，不改变 A 的真实碰撞位置或弹体生成点。
- 箭头表达打击作用方向，不承诺重力作用后的完整轨迹，不显示完整连锁预测。
- 调整期间显示待提交方向；确认后改写本次打击方向，恢复正常时间；之后鼠标不能继续改变结果。
- 只改变打击冲量方向，强度与全局重力不变，A 继续受重力作用；不能重复叠加第二次打击，也不能清除重力等已有运动效果。

### 3.4 单具尸体弹体

- A 在有效伤害期间接触其他目标可伤害并穿透继续运动；普通目标不会物理阻挡、反弹或偏折 A，本轮基础目标被有效伤害后死亡。
- B 普通死亡，不继承冲量、不成为弹体、不触发慢速或改向。
- A 受重力影响，撞墙或落地后停止伤害；不做墙面或地面反弹。
- 真实碰撞和伤害状态决定结果，刀光、镜头、震动、箭头不得改变命中集合。

### 3.5 胜败与重试

- 全部目标死亡判胜，不能把仍在伤害过程中的局面提前判失败。
- 存在存活目标且有效伤害过程结束时判失败。
- 重试恢复对象、位置、一次攻击、时间倍率、镜头与本次尸体/伤害状态。
- 未命中、落出关卡、调整中 A 失效的具体结束流程见第 8 节，不用未确认的固定超时替代。

## 4. 表现与白模范围

### 4.1 表现目标 [已确认]

首次命中提供强震屏，镜头迅速拉近、聚焦并以 A 为目标。完成鼠标调整后镜头恢复，与进入聚焦的节奏对应；时间恢复后能观看弹体结果。命中、调整、确认、死亡和胜败应能区分。

强度和节奏可调；先用白模及基础资源，不制作正式角色、美术或 UI 资源包。

### 4.2 信息与可用性约束

- 鼠标、箭头、界面、镜头保持可操作的响应，不能因 0.02 倍速迟滞。
- 镜头平移、缩放或震屏不能在鼠标静止时意外改变选择；确认结果与当时可见箭头一致。
- 聚焦不能妨碍识别方向选择所需的目标；强震时长、拉近幅度及恢复节奏待白模验证。
- HUD 表达攻击次数、慢速/改向状态、确认提示、目标存活情况和胜败重试入口。
- 白模清楚区分狐狸、活敌人、A 弹体和普通死亡目标。

### 4.3 可调参数

移动速度、跳跃与二段跳、冲击速度/距离、基础打击冲量强度、重力、慢速倍率（基准 0.02）、箭头尺寸/锚点、聚焦倍率/偏移、进入与恢复时长、震动强度/衰减。

这些为作者调试参数，不表示玩家能力能改变强度或重力。测试记录实际参数，不把起始值当作最优值。

## 7. 暂不纳入
