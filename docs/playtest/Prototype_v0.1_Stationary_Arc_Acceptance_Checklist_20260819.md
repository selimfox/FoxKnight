# FoxKnight v0.1 原地弧斩验收清单

Build：v0.1 原地弧斩与单圈边界
日期：2026-08-19
目的：验证本轮功能与信息层级，不据此判断整体玩法已经成立。

## 测试前确认

- 当前 Prototype 场景的 `arc_radius` 为 100；`hitbox_tolerance_multiplier` 为 1.0，因此刀型边界与弧斩实际半径均为 100。
- 直线斩保持距离 400、宽度 80及原有位移逻辑。
- 本轮没有弧斩短位移、方向死区或位移箭头。

## 创作者人工验收

1. 按住左键，把鼠标放在狐狸附近。
   - 预期：只看到一个暖橙弧斩攻击圆。
   - 不应看到：第二个外圈、方向死区、位移箭头。

2. 保持按住左键，把鼠标移出暖橙圆。
   - 预期：切为冷青直线斩；狐狸周围保留一圈很弱的暖橙细线，提示移回圈内会变回弧斩。
   - 该弱圈不应看起来像第二层攻击。

3. 在边界内外往返移动鼠标。
   - 预期：每次真正换型只触发一次短促光效与轻微音效；同一侧移动不重复触发。

4. 在弧斩状态松开左键。
   - 预期：狐狸原地旋斩，全程不位移；暖橙刀光与狐狸同心，命中范围和瞄准圆一致。

5. 在直斩状态松开左键。
   - 预期：保持既有鼠标方向直线位移斩，冷青范围、路径与结果无回归。

6. 分别执行取消、空刀、部分命中。
   - 预期：右键取消不消耗唯一一刀；正式提交后不能补救；胜败结算与重试正常。

## 主观问题

- 原地弧斩与直线位移斩的定位是否比移动弧斩更清楚？
- 弧斩是否还有“真实命中范围看不见”的问题？
- 直斩状态的弱暖橙圈是否会被理解为额外伤害范围？
- 从圈内移到圈外时，是否能在松开前稳定预测当前刀型？
- 原地弧斩是否更有仪式感，还是显得过于被动？

## 证据边界

- Smoke Acceptance 通过只证明功能与状态边界正确。
- 视觉捕获只证明画面元素存在且可区分。
- “更自然、更有仪式感、更好玩”必须由人工试玩反馈判断。
