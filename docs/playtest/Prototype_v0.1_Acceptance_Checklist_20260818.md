## 2. 基础操作与流程

- [ ] **移动**：观察阶段和瞄准阶段均可用 WASD 移动，狐狸不会穿出场地边界。
- [ ] **进入瞄准**：按住鼠标左键进入瞄准，不立即出刀，HUD 仍显示一刀可用。
- [ ] **取消瞄准**：瞄准时点击右键返回观察；之后松开左键不会误出刀，也不会消耗攻击机会。
- [ ] **提交攻击**：再次按住左键瞄准并松开，只提交一次攻击；出刀后不能移动、改方向、取消或追加攻击。
- [ ] **结算与重试**：出刀后只进入一次胜利或失败结算；按重试键后狐狸、敌人、HUD 和攻击次数恢复初始状态。

## 3. 刀型选择与预告圈

### 3.1 近身弧形斩

- [ ] 鼠标位于刀型阈值圈内时，当前攻击范围为狐狸周围的**暖橙色圆形**。
- [ ] 外侧刀型预告圈为**低亮度蓝白色**，能够理解为“跨出去会变成远距直斩”。
- [ ] 外圈只做轻微明暗呼吸，没有缩放、扩张、填充或半径跳动。
- [ ] 当前攻击圆明显强于外圈；外圈不会被误认为同时生效的第二层攻击。

### 3.2 远距直线斩

- [ ] 鼠标位于阈值圈上或圈外时，当前攻击范围为**冷青／蓝白色矩形**。
- [ ] 外侧刀型预告圈变为**低亮度橙色**，能够理解为“回到圈内会变成近身弧斩”。
- [ ] 当前直斩范围明显强于外圈；外圈不会被误认为圆形攻击范围。

### 3.3 跨圈反馈

- [ ] 缓慢往返跨过阈值圈时，每次实际换型只出现一次更强的对应颜色闪光和一次轻微音效。
- [ ] 鼠标停留在同一侧时，没有重复闪光或音效连发。
- [ ] 保持鼠标不动、用 WASD 让狐狸跨过相对距离阈值时，刀型和反馈同样正确更新。
- [ ] 切换反馈能被注意到，但不会压过当前攻击范围或被误认为出刀。

## 4. 弧形斩方向、动作与命中

- [ ] 鼠标位于狐狸附近的小死区圆内时，位移箭头隐藏，松开后狐狸原地弧斩。
- [ ] 鼠标离开死区后，箭头始终从狐狸指向鼠标；WASD 移动不会改变箭头朝向规则。
- [ ] 靠近场地边缘时，箭头长度能够反映被边界裁剪后的实际短移距离。
- [ ] 松开左键后，狐狸沿提交瞬间箭头方向短移；之后移动鼠标或按 WASD 都不会修改方向。
- [ ] 狐狸播放区别于直斩的弧斩动作；暖橙圆弧刀光在短移期间跟随狐狸。
- [ ] 刀光表达的圆形范围与实际命中一致：进入圆形范围的敌人死亡，始终在圆外的敌人不会只因视觉扫过而死亡。
