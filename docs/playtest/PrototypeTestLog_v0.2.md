## 2. 记录字段

每条正式记录包括：Build/工作区定位、日期、场景、初始条件、关键参数、执行步骤、预期、实际、关联 SV/SV-AC/H2 编号、证据路径与结论。

结论使用“通过 / 不通过 / 阻塞 / 无法判断”，并区分：

- 功能：对应 SV-AC-01～10，不由可玩性评价代替。
- 表现：箭头、镜头、震动、时间响应与实际命中是否一致。
- 体验：H2-01～H2-04 的行为和解释，不把自动检查通过表述为有趣。
- 性能：仅记录真实测量及环境，不推断其他设备表现。

未决项 SV-OQ-01～05 关联场景在规则确认前不能按实现默认行为判通过。尚无构建时不填写虚构的 Build 哈希；提交后按项目规则关联首次包含该构建的提交。
