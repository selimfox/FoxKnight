## 1. 要验证的体验

玩家先利用横版移动、跳跃与方向冲击斩命中一个目标，再通过改变首次打击的作用方向，使该目标的尸体成为可连续命中其他敌人的弹体。

待验证假设：不同切入位置、目标和发射方向能产生有意义的结果差异，使玩家愿意主动尝试。功能正确、特效强烈或全灭有解均不能单独证明这个假设成立。

## 2. 用户已确认的范围

| 项目 | 本轮规则 |
| --- | --- |
| 空间 | 侧视 2D 横版，包含高低差；不同高度的敌人用于支持出刀前的瞄准与预判。 |
| 基础输入 | WASD 为方向，Space 跳跃及二段跳，X 冲击斩；键盘映射先在 Godot 工程中公开配置。 |
| 攻击次数 | 每次尝试只能挥出一刀；首先必须实际命中敌人，才能进入慢速改向状态。 |
| 冲击方向 | 冲击斩携带方向输入，如右、左上、右下，并使狐狸沿该方向位移。 |
| 首击 | 狐狸首次斩击命中的敌人记为 A；本轮只有 A 获得方向调整与尸体弹体能力。 |
| 慢速 | 首次命中后进入正常速度 0.02 倍的时间缩放，公开显示慢速状态。 |
| 狐狸运动 | 出刀后不再接受移动、跳跃或追加攻击输入，但继续完成原有冲击运动；命中不能直接把狐狸停住。 |
| A 的运动 | 调整期间 A 也以 0.02 倍速继续运动，箭头跟随 A；不是完全暂停或暂存到确认后才发射。 |
| 箭头 | 箭尾固定在 A 的初始受力方向一侧边缘；以箭尾为旋转圆心，鼠标调整朝向，左键确认。箭尾属于可视标记，不改变实体的实际碰撞位置。 |
| 能力边界 | 只改变本次斩击施加给 A 的冲量方向，不改变其强度或全局重力；A 继续受重力影响。用户已澄清原消息的输入笔误。 |
| 确认后 | 按确认方向执行本次打击的改向，恢复正常时间，后续自动演算；不再给其他尸体开放改向。 |
| A 命中 B | A 可以继续飞行并沿途伤害多个敌人；B 普通死亡，不继承冲量，不成为新伤害弹体，也不触发慢速改向。 |
| 弹体结束 | A 受重力影响；撞墙或落地后停止伤害。 |
| 胜败 | 全部目标死亡判胜；否则等待有效伤害过程结束再判失败，不能在狐狸斩击演出结束时提前判失败。 |
| 表现目标 | 命中提供强震屏和敌人聚焦；确认后镜头恢复。具体强度与节奏需要白模验证并开放参数。 |
| 资源 | 先用白模和基础占位资源，不制作正式美术包。 |
| 工程 | 用户同意在现有工程中使用新目录隔离横版 Demo。 |

鼠标调整期间的箭头作为方向预览；提交时应只改写首次打击的方向效果，避免把同一次打击重复叠加为第二次冲量。重力产生的效果应保留。具体状态维护交由技术设计说明。

## 3. 设计判断与验证边界

- 首次命中本身是进入能力状态的门槛。自由改向并不要求原始冲击方向继续约束最终发射方向；先按此玩法验证，不自行加入旋转角度限制。
- 高低差用于命中前的移动与方向预判，验证时检查它是否形成不同切入方式，以及重试路程是否变成重复负担。
- 箭头表达本次打击的作用方向，不承诺受重力影响后的完整轨迹，也不提供完整连锁预测。
- 本轮是单个尸体弹体的连续命中，不建立尸体间的冲量传播、弹体分叉或多次改向系统。
- 本轮时间能力为命中后的时间缩放；此前讨论的区域时间回溯不自动纳入。

## 4. 建议的表现与技术约束（待正式收录）

- 鼠标、箭头反馈、界面和镜头过渡按实际时间保持响应。
- 强震集中在命中瞬间，选方向阶段尽快稳定；聚焦时仍需看见作出发射选择所需的目标。
- 镜头缩放、平移和震动不得在鼠标静止时改变已选方向；确认结果应与当时可见箭头一致。
- 可调参数包括移动、跳跃、冲击斩速度与距离、打击冲量强度、重力、慢速倍率、箭头尺寸、聚焦倍率及过渡时长、震动强度及衰减。开放基础参数不表示玩家可以通过能力改变它们。
- 需要保证高速弹体命中可靠、同一目标伤害去重、死亡对象不继续作为活目标计数，以及重试完整复原时间与镜头状态。

## 5. 制作前仍需定下的规则

以下事项尚不能从已有确认中唯一推导；不作为默认已确认需求：

1. 原问题：首版敌人静止还是简单移动。后续已确认使用静止敌人，不攻击狐狸；以正式 GDD 的边界追踪为准。
2. 狐狸继续冲击后再接触其他活敌人时，斩击是否仍能直接造成伤害；建议首版仅首个接触产生有效斩击命中，以突出 A 的弹体作用。
3. 0.02 倍速仍会推进运动。若 A 在方向调整完成前已落地或撞墙，怎样关闭改向并进入后续流程，需要明确。
4. 不输入方向时的冲击斩朝向、冲击斩未命中后的结束条件及落出关卡的处理，需要在功能规格中写清。
